# Resúmenes semanales de novedades de IA

Historial de resúmenes semanales automáticos de lanzamientos, actualizaciones y despliegues de herramientas de IA (ChatGPT, Gemini, Claude, Kimi, Copilot, Grok, Meta AI, Mistral, Claude Code, OpenAI Codex, GitHub Copilot, Cursor, entre otras).

Cada resumen cubre una ventana de 7 días y se archiva con la fecha de generación como nombre de archivo (`AAAA-MM-DD.md`). Esta carpeta consolida en un solo lugar los resúmenes que antes se habían generado en ramas separadas sin fusionar (`resumenes_semanales_ia/`, `ai-weekly-summaries/`), para que todos queden trazables desde un único índice.

## Notas de mantenimiento

- Los resúmenes de semanas anteriores a esta consolidación vivían en pull requests separados y sin fusionar (uno por semana), lo que dificultaba ver el historial completo. Se copiaron aquí tal cual fueron generados originalmente, sin editar su contenido.
- Si en el futuro se detectan más resúmenes sueltos en otras ramas, deberían añadirse aquí siguiendo la misma convención de nombre (`AAAA-MM-DD.md`, fecha de generación) para mantener un único índice fiable.
